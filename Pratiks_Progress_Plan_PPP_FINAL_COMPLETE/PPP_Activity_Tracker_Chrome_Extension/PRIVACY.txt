PPP ACTIVITY TRACKER — PRIVACY SUMMARY

Collected locally:
- Website domain, for example github.com
- Active seconds associated with that domain
- Date
- User-selected category and tracking settings

Not collected:
- Full URLs
- Page titles
- Page content
- Search queries
- Form entries, passwords or messages
- Incognito activity unless the user explicitly enables the extension in incognito
- Data from other browsers or Chrome profiles

Data sharing:
- None. The extension contains no analytics, server endpoint or database.
- The PPP website receives summaries only through a local Chrome content-script bridge.
